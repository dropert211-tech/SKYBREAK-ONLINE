# SKYBREAK // Drone Arcade V3 — ZONE NETWORK

Аркадная 3D-игра на Python + Three.js с сетевой комнатой, глобальным каталогом пилотов и режимом публикации в интернете.

## Интернет-режим

Игра теперь использует **один порт**: HTTP и WebSocket работают на одном адресе. Это удобно для Render и других облачных хостингов.

- Страница: `/`
- WebSocket: `/ws`
- Состояние сервера: `/health`
- Глобальный каталог: `/api/global`

В браузере поле **FIELD LINK** можно оставить пустым. Если игра открыта с публичного адреса, она автоматически подключится к этому же адресу.

## Быстрый деплой

В проекте есть `Dockerfile`, `render.yaml` и `DEPLOY_RENDER.md`.

1. Залей папку проекта в GitHub.
2. В Render выбери **New → Blueprint**.
3. Выбери репозиторий.
4. Нажми Deploy.
5. Получишь ссылку `https://....onrender.com`.
6. Передай эту ссылку друзьям — все открывают её в браузере.

Radmin VPN и проброс портов для этого режима не нужны.

## Локально на Windows

Запусти `START_WINDOWS.bat` и открой `http://127.0.0.1:8000`.

## Управление

- WASD — движение
- Space — вверх
- Shift — вниз
- Мышь — обзор
- ЛКМ — аркадный удар
- Esc — пауза / выход из катсцены
