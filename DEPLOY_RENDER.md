# SKYBREAK — публикация в интернет

## Самый простой способ: Render

1. Создай аккаунт на GitHub.
2. Создай новый **публичный или приватный репозиторий** и загрузи в него содержимое этой папки.
3. Открой Render и выбери **New → Blueprint**.
4. Выбери свой GitHub-репозиторий. Render увидит `render.yaml` и `Dockerfile` автоматически.
5. Нажми **Apply / Deploy**.
6. После деплоя Render выдаст адрес вида `https://skybreak-zone-xxxx.onrender.com`.
7. Ты и друзья открываете **одну и ту же ссылку** в браузере.

### Важно

- Radmin VPN больше не нужен.
- Роутер настраивать не нужно.
- WebSocket работает через тот же публичный HTTPS-адрес: `/ws`.
- Поле `FIELD LINK` можно оставить пустым — игра сама подключится к текущей странице.
- `/health` используется Render для проверки сервера.
- На бесплатном хостинге сервис может «засыпать» при отсутствии активности, поэтому первый вход после простоя может занять некоторое время.

## Локальный запуск

Windows: `START_WINDOWS.bat`.

После запуска открой `http://127.0.0.1:8000`.
